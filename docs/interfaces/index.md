# HL7 CDA Dokumentation

## Über HL7 CDA

HL7 Clinical Document Architecture (CDA) ist ein XML-basierter Standard für den Austausch klinischer Dokumente im Gesundheitswesen. Im AKTIN Data Warehouse werden CDA-Dokumente für die strukturierte Erfassung und den Import von Notaufnahmedaten verwendet.
